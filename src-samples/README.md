# Selected Swift Samples

These files show a few parts of Clipify without publishing the complete app.

| Sample | What it shows |
| --- | --- |
| `MomentModelExcerpt.swift` | A simplified candidate-moment model and activity signals. |
| `MomentScoringExcerpt.swift` | The experimental confidence, preference, and rarity score. |
| `DetectorRegistryExcerpt.swift` | A small detector registry used to coordinate replaceable signal sources. |
| `PrivacyLockStateExcerpt.swift` | Protected-data handling for a camera and memory app. |
| `CaptureResourceCoordinatorExcerpt.swift` | One-owner handoff for shared camera and audio resources. |

The samples are shortened or simplified where needed. They do not include full detector implementations, model files, real media, locations, signal histories, databases, developer identifiers, keys, user data, logs, or the complete camera pipeline.
